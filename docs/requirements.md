# Taskal v2

## 1. コンセプト
スケジュールを管理することで、タスクも同時に効率的に管理する。スケジュールとその日の収支を記録したら勝手に簡易的な家計簿になっている。
スケジュールを中心に、タスク・収支が連動するアプリ。これからの自分の時間と金がどう動くか確認するアプリ。

## 2. 機能要件
### 2.1 スケジュール管理
- スケジュール登録
  - タスク
  - バイト
  - インターン
  - 課題
  - 授業
  - プライベート
  - サブスク・支払
- スケジュール編集
- スケジュール削除
- カレンダー表示（スケジュール表示）
### 2.2 タスク管理（スケジュールと紐づけ・双方向同期）
- 課題、バイト等、やるべきことに絞って管理
- 編集・削除可能にする
- スケジュールとは別画面でリスト型の表示
### 2.3 収支管理
- 収支見込
  - スケジュールから登録（任意）
- 収支実績
  - スケジュールから登録
  - 個別登録
- 実際の残高表示・初期登録
